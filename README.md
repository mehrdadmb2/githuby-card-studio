## 📖 درباره پروژه

**PostCard Pro Studio** یک اپلیکیشن تک‌صفحه‌ای (SPA) قدرتمند و کاملاً ریسپانسیو است که به شما امکان می‌دهد کارت‌پستال‌ها، دعوت‌نامه‌ها و یادداشت‌های هنری خود را با امکانات بی‌نظیر شخصی‌سازی کنید. با بیش از **۳۹ تم گرادیانت**، **۵۰+ فونت** پشتیبانی‌کننده از زبان‌های مختلف، **نقشه تعاملی**، **خروجی PNG و PDF** و **سیستم ترجمه‌ی پویا**، این ابزار برای هر نوع رویدادی – از تولد و جشن گرفته تا آشتی و دلتنگی – ایده‌آل است.

> ✨ **نکته ویژه**: این پروژه به‌طور کامل **ماژولار** طراحی شده و با افزودن فایل به پوشه‌های مشخص، قابلیت‌های جدید به‌صورت خودکار شناسایی و به سایت اضافه می‌شوند.

## ✨ ویژگی‌های کلیدی

### 🎨 **تم‌ها و شخصی‌سازی پیشرفته**

| دسته‌بندی | تعداد | توضیح |
|-----------|-------|--------|
| **تم‌های پایه** | ۳ عدد | دارک، لایت و گلس‌مورفیسم |
| **تم‌های رویدادی** | ۶ عدد | تولد، آشتی، عشق، سفر، دلتنگی، دعوت (با ایموجی‌های تزیینی در پس‌زمینه) |
| **تم‌های گرادیانت** | ۳۰+ عدد | شامل Sunset، Ocean، Forest، Night، Fire، Ice، Galaxy، Neon، Royal و ... |

### 🌍 **پشتیبانی از ۱۳ زبان زنده دنیا**

انگلیسی، فارسی، آلمانی، روسی، ژاپنی، اسپانیایی، فرانسوی، عربی، ترکی، ایتالیایی، پرتغالی، کرهای و چینی. با انتخاب هر زبان، تمام رابط کاربری و متن‌های پیش‌فرض به‌طور خودکار ترجمه می‌شوند.

### 🗺️ **نقشه تعاملی (Leaflet)**

- انتخاب لوکیشن با کلیک روی نقشه
- کشیدن نشانگر (Marker) برای تنظیم دقیق موقعیت
- نمایش مختصات جغرافیایی (طول و عرض)

### 📸 **خروجی‌های حرفه‌ای**

- **PNG** با کیفیت ۲.۵ برابر (مناسب برای چاپ)
- **PDF** در سایز A4
- **چاپ مستقیم** با مرورگر

### 🎭 **حالت‌های روحی و آب‌وهوا**

- **۸ حالت روحی**: خوشحال، مهربون، عصبی، بی‌حوصله، عاشق، ناراحت، هیجان‌زده، آرام
- **۷ حالت آب‌وهوا**: آفتابی، ابری، بارانی، برفی، طوفانی، بادی، مه‌آلود

### 🖼️ **مدیریت تصویر پس‌زمینه**

- آپلود تصویر دلخواه
- تنظیم شفافیت، سایه، اندازه فونت، فاصله خطوط و رنگ متن

### 😍 **انتخابگر ایموجی**

- بیش از ۳۰ ایموجی پرکاربرد
- امکان افزودن و حذف با یک کلیک
- نمایش ایموجی‌های انتخاب‌شده در کارت

### 📝 **قالب‌های سریع (Templates)**

- ۶ موضوع آماده: تولد، آشتی، عشق، سفر، دلتنگی، دعوت
- هر قالب شامل: عنوان، متن چندزبانه، ایموجی‌های مرتبط و تم اختصاصی

### 💾 **ذخیره‌سازی خودکار**

تمام تنظیمات شما به‌صورت خودکار در مرورگر (localStorage) ذخیره می‌شود و پس از بازگشت به سایت، آخرین وضعیت بازیابی می‌شود.

### 📱 **ریسپانسیو و سازگار با تمام دستگاه‌ها**

طراحی شده برای نمایش عالی در موبایل، تبلت و دسکتاپ.

### 🔄 **ماژولار و توسعه‌پذیر**

با افزودن فایل به پوشه‌های زیر، قابلیت‌های جدید به‌صورت خودکار به سایت اضافه می‌شوند:

- **فونت‌ها**: `assets/fonts/manifest.json`
- **زبان‌ها**: `assets/languages/` (فایل‌های JSON جدید)
- **تم‌ها**: `assets/themes/manifest.json`
- **قالب‌های متنی**: `assets/templates/` (فایل‌های JSON جدید)
- **تصاویر پس‌زمینه**: `assets/backgrounds/manifest.json`

## 🛠️ نصب و راه‌اندازی

### روش ۱: استفاده از GitHub Pages (پیشنهادی)

1. ریپازیتوری را **Fork** یا **Clone** کنید.
2. در تنظیمات ریپازیتوری، بخش **Pages** را فعال کنید و branch `main` را انتخاب کنید.
3. سایت شما در آدرس `https://[username].github.io/githuby-card-studio` در دسترس خواهد بود.

### روش ۲: اجرای محلی

```bash
# کلون کردن ریپازیتوری
git clone https://github.com/mehrdadmb2/githuby-card-studio.git

# ورود به پوشه پروژه
cd githuby-card-studio

# اجرا با هر سرور محلی (مثلاً با Python)
python3 -m http.server 8000
# یا با VS Code (Live Server extension)
```

سپس در مرورگر خود به آدرس `http://localhost:8000` بروید.

## 🤝 مشارکت در پروژه

ما از مشارکت شما استقبال می‌کنیم! برای کمک به بهبود پروژه:

1. ریپازیتوری را **Fork** کنید.
2. یک **Branch** جدید برای ویژگی یا رفع باگ خود ایجاد کنید.
3. تغییرات خود را **Commit** کنید.
4. یک **Pull Request** باز کنید.

### 🧩 قابلیت‌های پیشنهادی برای توسعه

- [ ] افزودن تم‌های جدید (با اضافه کردن به `manifest.json` و CSS)
- [ ] افزودن زبان‌های جدید (با ایجاد فایل JSON جدید در `assets/languages/`)
- [ ] افزودن قالب‌های متنی جدید (با ایجاد فایل JSON جدید در `assets/templates/`)
- [ ] بهبود انیمیشن‌ها و جلوه‌های بصری
- [ ] افزودن قابلیت ذخیره‌سازی در ابر (Cloud Storage)
